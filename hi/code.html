用 Cloudflare 免费轻松部署个人密码库（NodeWarden）

2026年03月18日 149次阅读 0条评论

开始前要准备什么

  • 一个可以正常登录的 Cloudflare 账号。
  • 一个可以正常登录的 Github 账号。
  • Fork NodeWarden 开源项目。

本期会用到的项目与网址

  • Cloudflare 官网
  • GitHub 官网
  • NodeWarden 开源项目
⚠️ 发布前先清理敏感信息。GitHub Pages 网站可以被公网访问。不要上传密码、API密钥、Cookie、私人照片原件、数据库文件或包含个人隐私的配置。GitHub Free 用户通常还需要使用公开仓库来部署 Pages。

在 GitHub 创建一个新仓库

  1. 注册登录 GitHub 账号

    打开 Github 官网，注册或登录自己的账户。

  2. Fork “NodeWarden” 开源项目

    1. 点击前往 NodeWarden 的官方仓库。
    2. 点击页面右上角的 Fork 按钮，将该项目完整复制到你自己的 GitHub 账号下。

  3. 修改 wrangler.toml 配置文件

    1. 把 wrangler.toml 重新命名为其他名称。
    2. 把 wrangler.kv.toml 更名为 wrangler.toml。

进行部署

  1. 注册登录 Cloudflare 账号

    打开 Cloudflare 官网，注册或登录自己的账户。

  2. 部署到 Cloudflare 中

    1. 找到 Cloudflare Workers 并打开。
    2. Continue with GitHub（连接 Github 账号）。
    3. 选择你 Fork 后的 NodeWarden 项目。
    4. 点下一步，进行部署。
    5. 部署完成后，打开生成的链接。

  3. 再次修改 wrangler.toml 配置文件

    确保里面只有 KV 配置，没有 R2 相关内容。

    1. 在 kv_namespaces 中增加 KV空间ID。 
      [[kv_namespaces]]
binding = "ATTACHMENTS_KV" 
id = "你的KV命名空间ID" 
preview_id = "你的KV空间ID"

      打开 CloudFlare主页，点击左侧的 “存储和数据库”，然后点击 “Workers KV”，找到 “xxx-attachments-kv” 复制ID。

    2. 在 d1_databases 中增加 D1数据库ID。 
      [[d1_databases]]
binding = "DB"
database_name = "nodewarden-db"
database_id = "这里填你的D1数据库ID"

      进入 D1 SQL Database（D1 SQL 数据库），找到你的数据库，点击去就可以找到你的 D1数据库UUID。

  4. 部署完成

    到此部署完成，绑定自定义域名即可访问。

基本配置

打开自定义域名，首次打开时，需进行基础配置

  1. 配置 JWT_SECRET

    进入 Cloudflare 控制台 -> Workers 和 Pages -> 你的项目 -> 设置 -> 变量和机密 -> 添加。

    • 类型：秘钥
    • 变量名称：JWT_SECRET
    • 值：在基本配置页面里可以获取的到

  2. 创建账号&主密码

    按照界面中指示来即可。

    主密码一定要记住，非常重要。

到 Bitwarden 中使用

  1. 在 Bitwarden 项中，选择自托管

    指定您的本地托管 Bitwarden 安装的基础 URL。例如：https://xxx.domain.com

    注意，域名后面不要带 / 斜杠
