在 GitHub 创建一个新仓库

  1. 注册登录 GitHub 账号

    打开 github.com，登录自己的账户。

  2. Fork “NodeWarden” 开源项目

    1. 点击前往 NodeWarden 的官方仓库 。
    2. 点击页面右上角的 Fork 按钮，将该项目完整复制到你自己的 GitHub 账号下。

  3. 修改 wrangler.toml 配置文件

    1. 把 wrangler.toml 重新命名为其他名称。
    2. 把 wrangler.kv.toml 更名为 wrangler.toml。

进行部署



  1. 注册登录 Cloudflare 账号

    打开 https://dash.cloudflare.com，登录自己的账户。

  2. 部署到Cloudflare

    1. 打开 Workers 。
    2. Continue with GitHub 。
    3. 选择你 Fork 后的仓库 NodeWarden，下一步 。
    4. 部署 。
    5. 打开生成的链接 。

  3. 再次修改 wrangler.toml 配置文件

    确保里面只有 KV 配置，没有 R2 相关内容。

    1. 在 kv_namespaces 中增加 KV空间ID。 
      [[kv_namespaces]]
binding = "ATTACHMENTS_KV" 
id = "你的KV命名空间ID" 
preview_id = "你的KV空间ID"

      打开 CloudFlare主页，点击左侧的 “存储和数据库”，然后点击 “Workers KV”，找到 “xxx-attachments-kv” 复制ID。

    2. 在 d1_databases 中增加 D1数据库ID。 
      [[d1_databases]]
binding = "DB"
database_name = "nodewarden-db"
database_id = "这里填你的D1数据库ID"

      进入 D1 SQL Database（D1 SQL 数据库），找到你的数据库，点击去就可以找到你的 D1数据库UUID。

  4. 部署完成

    到此部署完成，绑定自定义域名即可访问。



基本配置



打开自定义域名，首次打开时，需进行基础配置

  1. 配置 JWT_SECRET

    进入 Cloudflare 控制台 -> Workers 和 Pages -> 你的项目 -> 设置 -> 变量和机密 -> 添加。

    • 类型：秘钥
    • 变量名称：JWT_SECRET
    • 值：在基本配置页面里可以获取的到

  2. 创建账号&主密码

    按照界面中指示来即可。

    主密码一定要记住，非常重要。



到 Bitwarden 中使用



  1. 在 Bitwarden 项中，选择自托管

    指定您的本地托管 Bitwarden 安装的基础 URL。例如：https://xxx.domain.com

    注意，域名后面不要带 / 斜杠
